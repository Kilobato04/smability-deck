# images/

Coloca aquí los logos de Smability. El HTML ya los busca con estos nombres:

| Archivo | Uso | Formato recomendado |
|---|---|---|
| `logo-smability-mark.svg` | Ícono cuadrado del encabezado (38×38 px). Si no existe, se muestra la "S" de respaldo. | SVG cuadrado, fondo transparente |
| `favicon.svg` | Ícono de la pestaña del navegador (incluye uno provisional). | SVG cuadrado |

Opcionales para siguientes versiones:

- `logo-smability-horizontal.svg` — logotipo completo (ícono + texto) para reemplazar `<span class="brand-name">` en `index.html`.
- `og-image.png` — imagen de 1200×630 px para vista previa al compartir el enlace.

Usa SVG siempre que sea posible (nítido en cualquier pantalla y ligero). Si sólo hay PNG, súbelo al doble de tamaño (76×76 px para el ícono) y cambia la extensión en `index.html`.
